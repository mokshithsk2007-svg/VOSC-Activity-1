# Tic-Tac-Toe Game

A modern, responsive two-player Tic-Tac-Toe game built with **only HTML, CSS, and JavaScript**.
Created for the **VOSC Activity-1** submission.

## Features

- 2-player gameplay (X and O) on the same device
- Responsive 3×3 board that works on desktop, tablet, and mobile
- Live turn indicator showing whose turn it is
- Automatic winner detection with highlighted winning cells
- Automatic draw detection
- Invalid move prevention (occupied cells and finished games cannot be clicked)
- **New Game** button to restart the board
- Scoreboard tracking X wins, O wins, and draws, with a **Reset Scores** button
- Modern glassmorphism UI with hover effects and animations
- Keyboard accessible (Tab + Enter/Space) and supports reduced-motion settings
- No frameworks, libraries, backend, or external dependencies
